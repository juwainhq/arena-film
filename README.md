# arena-film

A static WebGL 2 photo and video effects editor. The app lives in `index.html`; the HEIC/HEIF decoder and portrait-mask model in `vendor/` are loaded only when needed. Serve the repository through a local web server (for example, `python3 -m http.server 8000`).

All 40 sliders run from -100 to +100, centered at neutral 0. Red adds an effect; white reduces or reverses it. Negative Bloom and Hallation subtract glow, negative Grain inverts its noise, negative Sharpen softens, and negative Vignette Strength brightens edges. Four Color & Light controls add selective vibrance, a lift/crush for blacks, teal-to-plum shadows, and icy-to-amber highlights; at 0 they leave existing looks untouched. Double-click any slider to reset it to 0; R resets everything. Each effect section has an ON/OFF switch that bypasses rendering without erasing its slider values; its chevron button expands or collapses the advanced controls. Eighteen built-in looks and custom presets are available: the original six appear as quick picks, while six feed favorites, six color stories (Teal & Ember, Rosé Haze, Chrome Flash, Instant Film, Coastal Fade, After Hours), and saved looks live in the grouped **More presets** dropdown. Select a saved look to reveal its Delete button; saving a look adds it to the dropdown. Built-in looks leave sharpening and dithering at 0; manual adjustments and custom presets remain available. Older custom presets load with any new controls at 0; earlier versions migrate into localStorage v4.

Dither is a separate ON/OFF effect: move its signed intensity left for a monochrome print or right for a color print; 0 leaves the image unchanged. Color Steps and Dot Size adjust the pattern. Choose **Full photo** or **Background only**. For photos, Background only lazily runs the locally bundled [MediaPipe Selfie Segmentation](vendor/mediapipe-selfie/README.md) model to protect people without uploading the image; use Protect and Erase brushes for non-person subjects or to refine the result. Background Only waits for a detected or painted subject rather than unexpectedly dithering the entire image. While brushing, drag-to-pan is paused (wheel and button zoom still work); tap Done painting on the preview (or the active brush again) to resume panning. On phones, selecting a brush brings the preview into view. Masks belong to the currently loaded photo and reset on the next upload or Clear Mask. Saved custom presets remember the selected scope but not the photo-specific mask; built-ins and older saved presets use Full photo. Background-only selection is unavailable for videos; video dithering covers the full frame. Grain stays **still on photos** regardless of Grain Speed (including exports and older presets); Grain Speed continues to animate video grain.

Photos can be imported as JPG, PNG, HEIC, or HEIF (including uppercase extensions and files with an empty MIME type). If the browser cannot decode HEIC/HEIF natively, Film Lab lazily converts it to PNG in the browser with the bundled [heic2any 0.0.4](vendor/LICENSE.heic2any.md) decoder; the photo is never uploaded to a server. If you copy only `index.html` without `vendor/`, the decoder can fall back to a CDN when online. Photo export remains PNG. Video export (up to 60 seconds) lazily loads ffmpeg.wasm from a CDN, so it needs network access; WebCodecs `VideoFrame` is used for frame uploads where supported, with a video-element/canvas fallback.

Hover over the preview and scroll to zoom from 50% to 500%, or use the − / + buttons (also available on touch screens). Drag the picture to pan when zoomed in; click the percentage to reset to fit. Double-clicking the picture opens the file picker when no mask brush is selected. Zoom changes only the preview, never the exported pixels.

The header follows the portfolio's 24px / 40px / 64px navigation gutters. On narrow screens the editor actions stay visible in a second row. The icon-only sun/moon button switches the entire editor UI while keeping the rendered media and exports untouched; the choice is saved locally in `film_lab_theme` (dark by default). In light mode, black replaces white for negative slider fills so they remain visible. The portfolio-style dot-and-ring cursor follows the pointer on desktop, expands over interactive elements, and leaves the normal cursor available; it is disabled for touch and reduced motion.

Run the dependency-free control, dither, cursor, theme, HEIC, and zoom tests with `node --test tests/*.test.cjs`.
